# Σελίδες εκτός πρώτης εκκίνησης

Strategy, Ομιλίες, Αποτελέσματα. Επιστρέφουν με `git mv later/<φάκελος> src/app/<φάκελος>` και επαναφορά στο μενού (`src/lib/site.ts`), στο sitemap, στην αρχική (`src/app/page.tsx`: Results, Speaking· `WorkWithMe` στο `src/components/home.tsx`) και στο θέμα επικοινωνίας (`src/app/epikoinonia/page.tsx`).

Το Strategy περιμένει το υλικό παράδοσης: δες `docs/strategy-ypiresia.md`.

Το Mentoring και το Education είναι στο `src/app`. Οι ομιλίες (θέματα και μορφές) είναι μέσα στη σελίδα Education.
